La session est protégée par deux mots de passe : votre identifiant YunoHost sur le
portail, puis un mot de passe VNC demandé par le client navigateur. Lisez-le avec :

```bash
yunohost app setting obsidian vnc_password
```

Créez votre premier coffre depuis le bouton « Open folder as vault » de
l'application ; il sera stocké dans `/home/yunohost.app/obsidian/`.
